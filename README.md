# QA Test Portfolio – Rodion Petrushevskyi

Welcome to my public QA portfolio. This repository includes manual test cases, reusable checklists, and API validation examples — all based on my experience as a **Senior Manual QA Engineer** with 4+ years in testing complex web and API-based systems.

## 📁 Structure

### 🔹 `/test-cases/`
Manual test cases based on real-world product flows:
- `login_test_cases.md` – user authentication scenarios
- `registration_test_cases.md` – account creation validation
- `checkout_test_cases.md` – e-commerce purchase process
- `analytics_dashboard_cases.md` – data display and filters
- `sql_data_validation.md` – database accuracy testing
- `api_user_management.md` – REST API endpoint testing
-  `profile_settings_test_cases.md` - user setting
  

### 🔹 `/checklists/`
Reusable checklists for day-to-day QA work:
- `ui_checklist.md` – basic UI standards
- `smoke_checklist.md` – must-have tests for build validation
- `regression_checklist.md` – areas prone to breakage
- `api_checklist.md` – typical API-level checks
- `release_go_live_checklist.md` – pre-release confidence

## 🎯 Goals

This repo demonstrates:
- My structured approach to test documentation
- Attention to product quality from UI to backend
- Experience with SQL, Postman, Docker, and test tools
- QA mindset oriented toward release stability and business value
