# UI Checklist

## Purpose:
To verify that the user interface is consistent, visually correct, and user-friendly across devices and resolutions.

### 🔹 General Layout
- [ ] All elements are aligned correctly
- [ ] Text is not cut off or overflowing
- [ ] Consistent font family, size, and color across pages
- [ ] Colors match the design specification (including contrast ratios)
- [ ] Responsive layout adjusts properly on different screen sizes

### 🔹 Forms & Fields
- [ ] Labels are present and clearly associated with inputs
- [ ] Placeholder text is informative and visible
- [ ] Required fields are clearly marked
- [ ] Error messages are visible, clear, and relevant
- [ ] Input validation works (email, phone, etc.)

### 🔹 Buttons & Links
- [ ] Buttons are styled consistently (size, color, shape)
- [ ] Disabled buttons are visibly different
- [ ] Hover and active states are present
- [ ] Clicked links and buttons trigger correct actions
- [ ] All links open expected destinations

### 🔹 Visual Elements
- [ ] Icons load correctly and are not pixelated
- [ ] Images load and scale correctly
- [ ] Loading indicators are shown when needed
- [ ] Tooltips/popups appear in correct positions

### 🔹 Accessibility (basic)
- [ ] Elements are reachable via Tab navigation
- [ ] Focus outline is visible for active elements
- [ ] ARIA labels are present (where applicable)
- [ ] Color is not the only method of conveying information
